# 开源测试怎样参考

参考来源：https://github.com/zgd-dev/-V2.0 ，查阅日期2026-11-16。

可以参考公开的测试场景、操作顺序、异常现象与预期行为，保留来源；作者的实际结果属于作者的板卡与固件。当前公开README描述了断网缓存/补传/看门狗等功能和使用步骤，但本次读取的公开README中未附逐项带固件哈希、原始输出和时间的完整实验记录。因此这里按功能重新整理验收用例，不伪造作者或本机的测试次数、时长和通过结果。

用户已说明此前完成过相关复现。可以将记忆整理为“历史复现记录”，但缺少版本/照片/原始记录时如实写“版本未留存”，不要给它补造本次固件哈希。

## 本版本验收步骤

|ID|操作|应观察的内容|结果|
|---|---|---|---|
|HW01|正常连接传感器与Broker，运行5分钟|值与参考值相符；SENT/LIVE增加；DISK基本为0|未测|
|HW02|拔RS485再插回|OFFLINE后恢复；网络和屏幕任务继续运行|未测|
|HW03|拔网线60秒|WHY=CABLE，RAM分批转DISK，DISK增长|未测|
|HW04|接回网线|MQTT恢复，历史消息先上报，DISK下降|未测|
|HW05|服务器主动拒绝凭据|WHY=AUTH，观察connack_code；无快速重连风暴|未测|
|HW06|服务器不回PUBACK|WHY=PUBACK，消息保留，重连后允许重复|未测|
|HW07|DISK非空时断电重启|完整落盘消息保留，半写记录被跳过|未测|
|HW08|在线时突然断电|允许尚在RAM中的消息丢失；不要按零丢失判定|未测|
|HW09|故障注入屏蔽任务心跳|运行后IWDG复位，RESET记录可追溯|未测|
|HW10|长按/短按浏览所有页|4页可切换，诊断页长按切换日志等级|未测|
|HW11|30秒不操作再按键|仅背光关闭，采集网络仍工作，按键唤醒|未测|
|HW12|长时间运行，自定24/72小时|记录开始结束、最小堆、复位/错误/丢弃计数|未测|

HW01里的5分钟、HW03里的60秒是建议操作时长，HW12的24/72小时是待执行计划，均不是已经完成的结果。

## 记录实际结果

完成操作后运行，例如：

```powershell
python tools/record_test.py --id HW03 --result PASS --observed "拔线60秒，DISK由0变为58，页面继续刷新" --evidence "docs/assets/自己的截图文件.png"
```

上面的数值只是填写格式示例，必须换成实际读数。工具自动记录北京时间、版本、Git提交和本机Debug ELF哈希。文件在docs/results/hardware.csv。请同时保留实际烧录的ELF或其哈希，防止构建产物和板上程序不是同一版。
