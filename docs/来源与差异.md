# 来源与差异

参考仓库：https://github.com/zgd-dev/-V2.0 （MIT，Copyright (c) 2026 zgd）
镜像：https://gitee.com/china-growth-dynamics/zgd

本版本基于用户原有STM32F407工程和实际接线重新组织应用代码，参考上游功能清单；没有把ESP8266驱动当成W5500驱动，也没有把触摸屏代码套到无触摸的小屏上。原仓库README对F407/F411有混合描述，本版本以实际F407ZGT6和链接容量为准。

|参考方案|本版本|
|---|---|
|ESP8266 AT/Wi-Fi|W5500 SPI/有线TCP|
|较大触摸屏|240×240 ST7789，无触摸，按键导航|
|SP3485/不同UART|MAX3485，USART3 PD8/PD9，PD10方向|
|W25Q64|保留8MB容量，SPI2 PB12～PB15|
|定时喂狗|检查任务心跳后集中喂狗，任务失活停止喂狗|
|联网路径|自己封装MQTT3.1.1，QoS1确认后标记缓存|
|低功耗息屏|只关背光，不宣称MCU进入低功耗模式|

应用代码进行了文件分组、启动入口清理和新增功能实现；第三方组件保持原许可标识。不要把参考项目作者、MIT许可或ST/Arm/WIZnet版权删除。也不要把参考功能复现说成所有底层组件均为自研。

本次工具未能完整克隆参考仓库，读取了公开README和文件目录；新增网络与外部存储代码为针对现有硬件的重新实现，并非上游逐文件复制。这个事实不会改变功能验收要求，测试结果以本版本记录为准。
