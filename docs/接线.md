# 接线

主控为 **STM32F407ZGT6**，不是引用文字中的 F411。沿用原板 8MHz HSE、168MHz 系统时钟。

|模块|信号|F407引脚|
|---|---|---|
|W5500|SCK / MISO / MOSI|PA5 / PA6 / PA7（SPI1）|
|W5500|CS / RST|PA4 / PC4|
|ST7789 240×240|SCL / SDA|PB3 / PB5（SPI3）|
|ST7789|CS / DC / BL|PD11 / PD12 / PD13|
|MAX3485|DI / RO / DE与RE方向控制|PD8 TX / PD9 RX / PD10|
|W25Q64|CS / CLK / DI / DO|PB12 / PB13 / PB15 / PB14（SPI2）|
|W25Q64|WP / HOLD|均接3.3V|
|按键|低电平按下|PA15|
|板载LED|状态翻转|PC13|
|ST-Link|SWDIO / SWCLK / GND|PA13 / PA14 / GND|

1. W25Q64和MCU逻辑使用3.3V，所有通信模块共地。先断电接线。
2. MAX3485 的 A/B 接传感器 A/B；传感器供电按传感器规格，不由MCU GPIO供电。
3. W5500 的 RJ45 接电脑网口或交换机/路由器；ST-Link 负责调试，不传输以太网业务数据。
4. ST7789不带触摸，本版本用实体按键，不包含开源项目的触摸控制器。
5. PB3、PA15已经用作外设/按键，保持SWD模式，不启用占用它们的完整JTAG。
6. SPI2由 `App/Drivers/w25q64.c` 手动初始化。`docs/cubemx_base.ioc` 仅留作原板外设参考，不是当前工程完整生成器；重新生成前必须同步 SPI2、IWDG、任务创建和链接分区。

ST7789的排线与开发板板载屏座连接沿用此前接法；不要把PD13背光与PB13外部Flash时钟混淆。
