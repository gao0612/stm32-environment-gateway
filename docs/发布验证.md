## 自动测试内容

- 缓存记录保存、重启恢复、错误编号 ACK 拒绝、正确 ACK 后删除。
- 提交写入中断、半写记录跳过、CRC 损坏拒绝。
- 65,536 条缓存写满时保护未确认数据，确认后回收扇区。
- 日志环回、重启定位、等级筛选、样本身份持久化。
- MQTT CONNECT / SUBSCRIBE / QoS1 PUBLISH 编码和长度边界。
- 实际网络任务函数的认证拒绝、握手、分包与合包应答。
- RAM 消息确认后释放、Flash 历史优先、断连保留未确认数据和退避增长。
- CubeMX 初始化归属、用户入口、保护的 Flash 分区检查。
