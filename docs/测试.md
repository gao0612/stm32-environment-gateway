# 本版本测试

## 本机测试

执行 `python tests/run_tests.py`，需要电脑端GCC（不是arm-none-eabi-gcc）。

测试直接编译实际 `flash_store.c` 与 `mqtt_packet.c`，Flash模拟器限制只能从1写0：

- 数据保存、重启扫描、未确认数据保留、错误编号ACK拒绝。
- 正确ACK后逻辑删除，重启不再补传该记录。
- 在commit写入中注入失败，重启拒绝半写记录，再次保存跳过脏地址。
- 修改记录内容，CRC检测并拒绝损坏记录。
- 填满65536条缓存，验证不擦除未确认数据；确认一个扇区后可回收。
- 日志跨环回写、重启后的最新记录定位。
- MQTT CONNECT精确报文、用户名/密码标志、长度边界。
- QoS1 PUBLISH、SUBSCRIBE、跨128字节剩余长度编码。
- 逐字节分包、超长与非法剩余长度拒绝。

模拟测试不验证SPI电气时序、网线、真实Broker、HAL行为、任务实际栈余量和Flash耐久性。
